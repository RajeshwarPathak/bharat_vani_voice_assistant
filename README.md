# 🇮🇳 Bharat Vani — Indian AI Desktop Assistant & Extension

### Quick Start Options (No Browser Tab Needed!)

1. **Create Desktop Shortcut**:
   - Double-click `Create Desktop Shortcut.bat` to place the Bharat Vani icon on your Windows Desktop.

2. **Launch Desktop App**:
   - Double-click `Launch Bharat Vani (Desktop App).bat` to immediately launch the dedicated native Windows app window.

3. **Install Browser Extension**:
   - Open `chrome://extensions` or `edge://extensions`
   - Enable "Developer mode"
   - Click "Load unpacked" and select: `bharat-vani\extension`
   - Press `Ctrl + Shift + V` to open the side panel!
