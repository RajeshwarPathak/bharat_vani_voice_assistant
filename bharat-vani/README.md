# Bharat Vani

The complete installation, configuration, feature, troubleshooting, and development guide is in the repository [README](../README.md).

## Fast Start

```powershell
npm install
Copy-Item .env.example .env
# Add GEMINI_API_KEY to .env
python -m pip install SpeechRecognition PyAudio
npm run app
```

You can also double-click `Launch Bharat Vani (Desktop App).bat`.

For the desktop shortcut, run `Create Desktop Shortcut.bat`. For Chrome or Edge, load the `extension` folder as an unpacked extension after starting Bharat Vani.
