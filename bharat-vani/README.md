# 🇮🇳 Bharat Vani — Indian AI Desktop Assistant & Extension

Bharat Vani is an AI Voice & Vision Assistant designed for Indian users with multilingual support (Hindi, Hinglish, English), system automation, and seamless non-browser usage formats.

---

## 💻 1. Standalone Desktop App Format (No Browser Needed)

You do **not** need to open Bharat Vani in a browser tab! Use the dedicated desktop application:

### Method A: One-Click Desktop Shortcut (Recommended)
1. Double-click `Create Desktop Shortcut.bat`.
2. A **"Bharat Vani AI"** shortcut will appear on your Windows Desktop with the custom app icon.
3. Double-click the shortcut anytime to open the standalone desktop window!

### Method B: Double-Click Launcher
- Double-click `Launch Bharat Vani (Desktop App).bat` in this folder.
- It will automatically bootstrap the server in the background and open the native window.

### Method C: Terminal Command
```bash
npm run app
```
or
```bash
npm run electron
```

---

## 🧩 2. Browser Extension Format (Chrome & Edge Side Panel)

If you are browsing or working on the web and want Bharat Vani docked right next to your active tab:

1. Open `chrome://extensions` (in Chrome/Brave) or `edge://extensions` (in Edge).
2. Toggle ON **Developer mode** (top-right).
3. Click **"Load unpacked"** and select the folder:
   ```
   the `extension` folder inside the extracted Bharat Vani project
   ```
4. Press **`Ctrl + Shift + V`** to toggle the Side Panel on any website!
5. Highlight any text on any webpage, right-click, and choose *"Ask Bharat Vani"*.
