# 🇮🇳 Bharat Vani — Chrome & Edge Browser Extension

Access **Bharat Vani AI** directly from any webpage in your browser's **Side Panel** or **Toolbar Popup** without having to open a separate tab!

---

## 🚀 How to Install in 30 Seconds

### Step 1: Open Extension Management
- **In Google Chrome / Brave:** Navigate to `chrome://extensions`
- **In Microsoft Edge:** Navigate to `edge://extensions`

### Step 2: Enable Developer Mode
- Turn ON the **"Developer mode"** toggle switch in the top-right corner.

### Step 3: Load Unpacked Extension
- Click the **"Load unpacked"** button in the top-left.
- Select this folder:
  ```
  the `extension` folder inside the extracted Bharat Vani project
  ```

🎉 **That's it!** The Bharat Vani logo will appear in your browser toolbar.

---

## ⚡ Shortcuts & Features

| Action | Shortcut / Trigger |
|---|---|
| **Toggle Side Panel** | Press `Ctrl + Shift + V` (or `Cmd + Shift + V` on Mac) |
| **Quick Popup HUD** | Press `Alt + V` or click the extension icon |
| **Ask About Selected Text** | Highlight any text on any website -> Right-click -> Select *"Ask Bharat Vani"* |
| **Summarize Current Tab** | Click *"📄 Summarize Page"* in the side panel ribbon |
| **Hands-Free Voice** | Toggle *"Wake Word"* switch and say *"Hey Vani"* or *"Namaste Vani"* |

> **Note:** Ensure your Bharat Vani local backend is running (by double-clicking `Launch Bharat Vani (Desktop App).bat` or running `npm run app`).
